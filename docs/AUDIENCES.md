# Audiences

Audience presets live in `data/audiences/` and load into the typed
`AudienceProfile`. Each profile controls message priorities, vocabulary, reading
level, platform mix, imagery, humor, and CTA style without relying on
stereotypes.

The adapter creates one `CreativeBrief` from the product facts and profile.
Writers use the brief rather than independently guessing audience language, so
audience changes affect lead benefit, proof-point order, channel emphasis, and
imagery direction—not just adjectives. Custom audiences are normalized into the
same profile contract with inclusive defaults.
